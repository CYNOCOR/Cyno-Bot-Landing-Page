# CYNO BOT landing page

Marketing landing page for **CYNO BOT**, the robot receptionist by CYNOCOR (ATP Group 40, 2026).
Live at https://cynobot.cynocor.com

Plain HTML, CSS and JavaScript, no build step. Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

| Path | What it is |
|---|---|
| `index.html` | The landing page |
| `privacy.html` | Privacy notice for the demo request form |
| `css/style.css` | All styles |
| `js/main.js` | Menu, robot face, scroll reveal, form |
| `assets/` | Logos, robot screenshots, team photos |
| `_headers` | Security headers for the host |
